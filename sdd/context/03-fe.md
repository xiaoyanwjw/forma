# Context · Frontend（范本：picklist）

**何时读**：只改 Vue/TS / 路由 / api 时打开**本片**（不必开 `02-be`）。  
**替换规则**：`picklist` / `Picklist` → 你的域。  
**索引**：[`01-coding-style.md`](./01-coding-style.md) · 后端：[`02-be.md`](./02-be.md)

## 范本根路径

`forma-web/src/` 下：

| 种类 | 路径 |
|------|------|
| 页面 | `views/business/picklist/` |
| 组件 | `components/business/picklist/` |
| 跨页标签 | `components/common/`（仅跨页复用） |
| API | `api/business/picklist/picklist.ts` |
| 类型 | `types/business/picklist.ts` |
| composable | `composables/business/picklist/` |
| Agent 壳 | `views/agent/` · `composables/agent/`（对话 + SSE + 预览；对齐 UX mockups） |

## 调用链

```text
views/Picklist*.vue
  → api/business/picklist/picklist.ts（仅 HTTP 动词函数）
  → types/business/picklist.ts（interface / type / enum）
  → HTTP 客户端 → /api/v1/picklists
```

计费生成：Agent 壳用 **fetch + ReadableStream** 带 JWT 读 SSE；**禁止**原生 `EventSource`（无法自定义 Authorization）。事件名见 Spine AD-4。

| 要创建… | 命名成… | 放在… |
|--------|---------|--------|
| 列表页 | `PicklistList.vue` | `views/business/picklist/` |
| 详情 | `PicklistView.vue` | 同目录；**入场用路由 id + `get*`** |
| API 模块 | `picklist.ts` | `api/business/picklist/` |
| 类型 | `Picklist`, `CreatePicklistRequest` | `types/business/picklist.ts` |

## 1. 目录配方

```text
forma-web/src/
  views/business/picklist/
  components/business/picklist/
  components/common/
  api/business/picklist/picklist.ts     # 只放 HTTP；禁止 export type/interface
  types/business/picklist.ts            # 类型唯一出处
  composables/business/picklist/
  views/agent/                          # 主入口对话壳
  composables/agent/                    # SSE / 会话
```

页面 + composable 够用就 **不要** 强行 Pinia。

---

## 2. 文件名

| 类型 | 规则 | Good | Bad |
|------|------|------|-----|
| `.vue` | PascalCase | `PicklistList.vue` | `picklist-list.vue` |
| `.ts` | camelCase | `usePicklistStatus.ts`, `picklist.ts` | `UsePicklistStatus.ts` |
| 路由 name | kebab-case | `picklist-list` | `PicklistList` |

---

## 3. 符号名

| 种类 | Good | Bad |
|------|------|-----|
| 组件 | 与文件名一致 | 不一致 |
| composable | `usePicklistStatus` | `picklistStatusHook` |
| API 函数 | `create`, `getPicklist`, `getPicklistList` | `fetchData` |
| 类型/枚举 | `Picklist`, `CreatePicklistRequest` | `getPicklistListRequest` |
| 字段 | `picklistId`, `userId`, `createdAt` | `picklist_id` |
| 类型 import | `import type { X } from '@/types/...'` | 从 `@/api/...` 再导出 type |

---

## 4. 路由配方

| name | path |
|------|------|
| `agent` | `/` 或 `/agent`（主入口，对齐 UX） |
| `picklist-list` | `business/picklist` |
| `picklist-view` | `business/picklist/view/:id` |

**编辑/详情加载**：路由参数 → `get*`；**禁止**靠 `history.state` / 列表行对象当真相。

---

## 5. Vue/TS 勾选

```
[ ] <script setup lang="ts"> + Composition API
[ ] import type；路径 @/
[ ] HTTP 只经统一客户端 + api/<区>/
[ ] 类型只在 types/<区>/；api 文件无 export interface/type（常量配置除外）
[ ] 详情页 onMounted：按路由 id 拉详情
[ ] SSE：fetch+ReadableStream + Authorization；不用 EventSource
[ ] catch 用 handleError（客户端落地后）且已 import
[ ] 禁止无注释 any
[ ] 有对应 router 条目
[ ] handler 顶部 early return（见 04-quality）
[ ] 不在前端存模型 Key / 改积分
```

**控制流 / 早返回**：[`04-quality.md`](./04-quality.md)

## 6. 遗留 · 勿扩散

| 看见 | 写成 |
|------|------|
| `frontend/src/...`（LIMS） | `forma-web/src/...` |
| api 内 `export interface` | `types/...`；api 只 `import type` |
| 编辑靠 `history.state` | `get*(id)` |
| 原生 EventSource 带 JWT | fetch 流式 |
