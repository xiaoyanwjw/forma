## 调用链

```text
*Request → Controller（薄，JWT 取 userId，组 Command）
  → ApplicationService（写 + @Transactional）→ 聚合 → Repository
  → QueryService（读）→ DTO
← ApiResponse.success(DTO)
```

计费生成（选品/Listing）另经 application 编排：`预占 → AgentSession → 成果落库 → 结算`；积分只走 CreditLedger（见 Spine）。

## 2. 类名 · Good / Bad

| 种类 | Good | Bad |
|------|------|-----|
| 聚合 | `Picklist` | `PicklistAggregate`, `PicklistEntity` |
| 子实体 | `PicklistItem` | `Item`（丢前缀）、`PicklistItemDO` |
| 状态 | `PicklistStatus` | `BusinessEnum`（勿扩散） |
| 写服务 | `PicklistApplicationService` | `PicklistService`, `PicklistManager` |
| 读服务 | `PicklistQueryService` | 把 `page/find*` 塞进 ApplicationService |
| 写命令 | `CreatePicklistCommand extends BaseCommand`（`@SuperBuilder`） | `PicklistCreateDTO` 当写命令；`new` + `set*`；不继承 BaseCommand |
| 查询入参 | `PicklistPageQuery` / `PicklistQuery`（同样 Builder） | `GetPicklistListCommand` |
| HTTP 入参 | `CreatePicklistRequest` | 与 Command 同一类跨层 |
| domain 只读投影 | `PiMessage` | `PiMessageDTO`（与 Application/HTTP 出口 `*DTO` 混淆） |
| 事件 | `PicklistGeneratedEvent` | `GeneratePicklistEvent`（动词开头易混） |

**命名避坑**：VO 已有 `GetXxxRequest` 时，Application 查询类用 `XxxPageQuery` / `XxxQuery`。

**Command / Query 创建**

- 一律 `XxxCommand.builder()…build()`（Lombok `@SuperBuilder`，继承 {@code BaseCommand}）。
- 所有写命令 **extends** `com.xmut.forma.common.command.BaseCommand`（字段：`userId`、`username` 为**操作者**）。
- Controller 组命令时显式 `.userId(SecuritySupport.requireUserId()).username(SecuritySupport.currentUsername())`；公开接口可空。
- 禁止 `new` + setter；禁止 Application 自己抠 SecurityContext。
- 特例：公开注册时 `BaseCommand.username` = 待注册用户名，`userId` 为空。

**Query 创建（读）**

- 一律 `XxxQuery.builder()…build()`（Lombok `@SuperBuilder`，继承 `com.xmut.forma.common.query.BaseQuery`）。
- **何时必须 `*Query`：** ≥2 个业务参，**或** 带分页 / 过滤；单参可读方法可暂留散参。
- `BaseQuery` 至少 `userId`（JWT sub）；读路径**不强制** `username`。
- Controller 组查询时显式 `.userId(SecuritySupport.requireUserId())…`；禁止 Application / QueryService 读 SecurityContext。
- limit / pagesize 默认值与上限写在对应 Query 的实例方法（如 `limit()` / `turnLimit()`），**不要**堆在 QueryService 静态 `clamp*`。
- QueryService 方法名优先：`list` / `page*` / `find*` / `getLatestArtifact`。

## 3. 方法名

| 层 | Good | 说明 |
|----|------|------|
| ApplicationService | `create`, `update`, `remove`, `generate` | **只写** |
| QueryService | `page`, `findById`, `findByUserId` | **只读** |
| Controller | `getPicklist`, `getPicklistPage`, `create` | HTTP 语义；列表与详情方法名勿相同 |

**禁止**同一 Controller 两个方法同名。

## 4. HTTP

| 项 | Good | 例 |
|----|------|-----|
| 集合 | `/api/v1/<复数>` | `/api/v1/picklists` |
| 单资源 | `/{id}` | UUID 字符串（Spine AD-12） |

## 5. common 守卫与日志

### 5.1 公共参数守卫（`StringUtils` / `ObjectUtils`）

路径：`forma-common/.../common/util/`

| 类 | 方法 | 用途 |
|----|------|------|
| `StringUtils` | `hasText` / `isBlank` | 只判断；禁止手写 `null \|\| trim().isEmpty()` |
| `StringUtils` | `requireHasText(s, msg)` | 非空白；默认 `PARAM_INVALID` |
| `StringUtils` | `requireHasText(s, ErrorCode)` | 非空白；自定义错误码 |
| `ObjectUtils` | `requireNonNull` | 对象非 null |
| `ObjectUtils` | `requireNotEmpty(Collection/Map)` | 集合 / Map 非空 |

失败抛 `BusinessException`。  
**域内规则**仍用 ApplicationService 私有 `require*`。  
优先 `com.xmut.forma.common.util.StringUtils`，勿与 Spring `org.springframework.util.StringUtils` 混用（业务守卫走本仓）。

### 5.2 监控埋点与业务日志（`LoggerUtils`）

路径：`…/common/logging/LoggerUtils.java` + `NameValue`（裁剪自 LIMS，无租户）。

| 类型 | API | 何时 |
|------|-----|------|
| 监控埋点（成对） | `LoggerUtils.success` / `error` | 流程关键节点：注册、预占、结算、释放、月重置… |
| 业务关键路径 | `LoggerUtils.warn` 或同格式 `error` | 可预期拒绝（积分不足）、CAS 冲突等 |
| 禁止 | 密码 / JWT / 密钥 | — |

格式：`[Forma_Monitor_V1] result=true|false, category=类名_方法, traceId=…, k=v`。  
`traceId`：HTTP 由 `TraceIdFilter` 写入 MDC（可透传 `X-Trace-Id`）。

```java
LoggerUtils.success(log, CreditApplicationService.class, "reserveOne",
        NameValue.create("userId", userId),
        NameValue.create("holdId", holdId));
```

## 6. Java 勾选

```
[ ] 构造器注入；@Slf4j @Service / @RestController
[ ] 写方法 @Transactional(rollbackFor = Exception.class)
[ ] Controller：JWT → SecuritySupport；Command.builder().userId(...).username(...).build()
[ ] Application / QueryService 不直接读 SecurityContext；操作者从 command/query.getUserId()（写路径可加 getUsername()）
[ ] 读走 QueryService；写走 ApplicationService
[ ] Command extends BaseCommand + @SuperBuilder；禁止 new+setter
[ ] Query extends BaseQuery + @SuperBuilder；≥2 参或分页/过滤必须 *Query
[ ] QueryService 操作者从 query.getUserId()；limit clamp 在 Query 实例方法
[ ] domain 只读投影勿用 *DTO 后缀；Application/HTTP 出口用 *DTO
[ ] 查询类名 *PageQuery / *Query，勿 Get*Command
[ ] 积分变更只经 CreditLedger；工具/Agent 禁止写账本
[ ] Listing 若有主图只存 mediaObjectId；URL 由 MediaStore 派生（近端可不强制主图）
[ ] 大类 // ── 模块 ── ，块内先读后写
[ ] 禁止 AppService 内与 domain 同名 private class
[ ] 参数空值用 StringUtils / ObjectUtils.require*；不手写空白判断
[ ] 流程关键节点用 LoggerUtils.success/error；不打 token/密码
[ ] 业务失败 BusinessException + ErrorCode
[ ] 分支：卫语句优先（见 04-quality）
```

**控制流 / 早返回**：[`04-quality.md`](./04-quality.md)

## 7. 遗留 · 勿扩散（相对 LIMS）

| 看见 | 写成 |
|------|------|
| `backend/lippi-ai-lims-*` 路径 | `forma-*` 平铺 |
| `TenantContext` / `tenantId` | `userId`（本产品近端单用户账本，无多租户） |
| `com.xmut.lims` | `com.xmut.forma` |
| `DT_Monitor_V1` / 审计专用 logger | `Forma_Monitor_V1`；审计落库另议 |

| `page`/`findById` 仍在 ApplicationService | 拆 `*QueryService` |
