# Glossary — Adam

| 术语 | 含义 |
|------|------|
| 选品清单 / Picklist | 一次生成得到的「可以卖什么」列表，含理由；目标约 8–12 条候选 |
| Listing 套装 / ListingPack | 一次生成得到的主图 + 详情页文案与展示说明，用于上架 |
| 积分 | 计量单位；成功生成选品清单或 Listing 套装各消耗 1 |
| 套餐 | 免费 / Pro / Plus；差异为每月积分额度 20 / 200 / 600 |
| 品类模板 | 按品类约束生成风格与字段；三档均可使用已上线模板 |
| 积分月重置 | 订阅周期到点按档位重发；未用完清零不结转 |
| 历史保留 | 本人近 **60 天**内的选品清单与 Listing 套装 |
| GenerationRun | 一次计费生成回合；关联预占、会话与成果 |
| CreditLedger | 积分唯一写入者（预占/结算/重置） |
| Agent 壳 | 对话主入口 + 快捷栏 + 右侧预览（见 EXPERIENCE） |
