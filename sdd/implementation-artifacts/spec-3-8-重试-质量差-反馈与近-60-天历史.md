## Intent

**Problem:** 选品/Listing 成功后，用户无法对不满意结果再跑一枪或留下「质量差」反馈，顶栏「历史」也只是占位页——过往成果无法回看，改进与找回都断了。

**Approach:** 工作台在可用成果上提供重试与「质量差」反馈；新建 Feedback 持久化（不扣生成分）；落地 HistoryQuery 读本人近 60 天 `picklist`/`sku` 成果并替换历史占位页（默认可筛场景）。

**Decisions:**
- 历史真相源 = `ebus_artifact`（可用成果），**不是** Session transcript / Checkpointer / GenerationRun 列表
- 列表类型仅 `picklist` + `sku`（不含 `chat`、不含 HITL 中间态 `listing_plan`）
- 重试 = 再调现有计费启动路径（新 Run + 新预占）；可复用同一 `sessionId`；**不**走 `/resume`、不复用旧 hold、不静默覆盖旧成果
- Feedback 独立表与所有权（AD-6），不改 `GenerationRun` 状态机；写入路径零 `reserve`/`settle`
- 顶栏「历史」改为可导航链到 `/history`（与 UX-DR1 一致）
- **历史详情（1A）：** 历史页内嵌 Computer 预览（点条目展开/侧栏展示 `payload_json.view`）；Listing 图经 MediaStore 重签 URL
- **质量差反馈（2A）：** 仅工作台成功态入口——一键标签「质量差」+ 可选短文；历史页本故事不提供反馈入口
- **重试交互（3A）：** 一键重试——复用上次提示词 + 同 `sessionId`，不弹编辑框
- **超窗数据（4A）：** 本故事只做查询窗口过滤（列表不出现 >60 天），不做物理清理任务

## Boundaries & Constraints

**Always:**
- JWT；历史/反馈仅本人；历史窗口 `created_at >= now-60d`；默认全球（全场景），可选 `sceneCode` 筛选（FR12, AD-15）
- 重试再扣分规则同选品/Listing（余额≥1→预占→可用成果 settle；失败 release）（FR11, AD-5/7）
- 「质量差」反馈可被后续分析读取；本动作不扣生成分（FR11）
- HistoryQuery 只读聚合；Feedback 唯一写反馈；CreditLedger 仍唯一写积分（AD-6）
- 顶栏契约与全站一致（UX-DR1 / UX-DR8）
- 历史详情在页内用 Computer 渲染 view；工作台成功态提供一键重试与「质量差」+可选短文

**Never:**
- 不做 3.5 超范围拉回产品化；不做 3.7 下载/复制导出产品化
- 不把重试做成同 Run 覆盖或复用旧 hold；不把 `/resume`/HITL 当重试；重试不要求用户改提示词
- 不把反馈字段塞进 `GenerationRun`；反馈路径不碰 CreditLedger；本故事不在历史页做反馈入口
- 不以 Session/Checkpointer 当 FR12 历史源；不按场景拆积分账本
- 不做运营后台反馈看板；不做用户删除历史；不做 >60 天物理清理（另议）

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| 重试成功 | 已有成功选品/Listing；余额≥1；点一键重试 | 复用上次提示词+session；新 Run+新预占；旧 artifact 仍在；成功则新成果 settle | 余额不足：不开始，人话去套餐 |
| 重试失败 | 模型/成果不合格 | release；旧成果不被覆盖 | `run_failed` 人话 |
| 提交质量差 | 工作台成功态；点标签±短文 | 落库；不扣分；可凭 id 读回 | 非本人/无成果：拒绝 |
| 历史默认列表 | 登录打开 `/history` | 本人近 60 天 picklist+sku，新在前 | 空列表友好空态 |
| 历史详情 | 点列表条目 | 页内 Computer 展示该成果 view（Listing 重签图） | 非本人：不可见 |
| 按场景筛 | 传 `sceneCode=ecommerce` | 仅该场景成果 | 非法 code：空或人话错误 |
| 他人成果 | 伪造他人 artifactId 反馈/详情 | 不可见/不可写 | 403/404 语义，不泄密 |
| 超窗 | 成果 >60 天 | 列表不出现（无物理删除） | N/A |

## Design Notes

### 三线关系（同故事，边界不交叉）

```
重试 ──► 现有 billed start（新 Run/hold）──► 新 artifact 行
反馈 ──► Feedback 表（无 CreditLedger）
历史 ──► HistoryQuery 读 ebus_artifact（60d + ACL + scene 筛）
```

### 重试 vs resume

- 重试：产品「再生成」→ 新计费动作
- `/runs/{id}/resume`：HITL 同 Run 续跑 → **禁止**当作重试入口
