## Intent

**Problem:** 登录用户没有真正的场景画廊首页：`/scenes` 只是占位文案，未拉 SceneCatalog；顶栏「场景」仍指营销 `/`，登录后落到套餐页。用户分不清「现在能做什么、以后有什么」。

**Approach:** 用 Catalog 列表 API 渲染大卡片画廊（桌面约 2×2：电商亮卡 + 三张灰卡标「即将推出」）；挂 AppHeader 且「场景」为当前页语义；登录后进入画廊而非提问门面。灰卡 toast、电商工作台空态分别留给 2.4 / 2.5。

**Decisions:**
- 画廊住 `/scenes`；登录/注册成功与顶栏 Logo/「场景」改指 `scenes`；`/` 仍营销 Landing
- 亮卡整卡可点，跳到预留电商工作台路由（占位页）；空态 UI 由 2.5 填充
- 无 JWT 仍调 `getScenes`；401 后清 token 并页内引导登录（不假装有卡）

## Boundaries & Constraints

**Always:**
- 卡片数据来自 `getScenes()`（`GET /api/v1/scenes`），按 `sortOrder` 展示；状态驱动亮/灰样式（`AVAILABLE` / `COMING_SOON`）
- 视觉对齐 UX mockup：内容柱约 960px、桌面 2×2、窄屏单列；亮卡整卡可点、无底部「开始使用」脚链；灰卡降饱和并标「即将推出」
- 顶栏用既有 `AppHeader`，画廊页 `activeNav="scenes"`；文案冷静短句，无内部黑话（UX-DR12）
- 复用 DESIGN token；焦点环可见

**Never:**
- 灰卡 toast / 引导去电商（→ 2.4）；工作台空态正文与完整面包屑壳（→ 2.5；本故事仅预留可进占位路由）
- 改 SceneCatalog 后端契约、种子或 CreditLedger
- 硬编码四卡文案绕过 API（失败降级文案除外）
- 紫渐变主题；用户可见「示意 / 近端 / 空壳」等黑话

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| 画廊加载 | 已登录，Catalog 返回四场景 | 大卡片网格：1 亮 + 3 灰「即将推出」；标题区产品文案 | N/A |
| 亮卡点击 | `AVAILABLE` 卡 | 进入预留电商工作台占位路由 | N/A |
| 窄屏 | 视口 ≤ 约 700px | 卡片单列 | N/A |
| 顶栏 | 在画廊页 | 「场景」呈当前页语义（高亮/`aria-current`） | N/A |
| API 失败 | `getScenes` 抛错/非 401 | 人话错误，不崩页、不假装有卡 | 弱提示 |
| 无/失效 JWT | `getScenes` → 401 | 清 token；页内人话引导登录；不展示假卡 | 与现有 401 清会话一致 |
