# PRD：Adam——场景壳 + 电商选品与 Listing（积分制）

*曾用工作名「AI 员工落地陪跑」。近端产品形态为自助工具，非人工陪跑服务。对外品牌名工作称呼：Adam。*

## 0. 文档用途

供产品决策、后续 UX / 架构 / 拆故事使用。能力用稳定编号 FR。技术选型（具体大模型、框架、编排实现）不在本文展开，见 `addendum.md` 与待决项。

## 1. 愿景

### 1.1 近端（3–6 个月）

让淘宝 / 闲鱼 / 拼多多上的一人店主，用网页自助拿到「可以卖什么」的清单（带理由），以及一套能上架的主图 + 详情素材——按积分消费，少做重复劳动，**不承诺一定卖得出去**。

**一句话差异（获客/融资叙事）：**  
给一人店主：点几下就拿到能卖的候选清单 + 能上架的主图详情；按次用积分，不绑千牛，也不要求先自建一套通用 Agent。

小程序在网页之后补。生意目标感：准主业月入约 1–2 万（目标感，非承诺）。

### 1.2 终局

- **电商纵深：** 选品 → 设计 → 询盘 → 客服 → 物流 → 收款尽量自动化。  
- **多场景扩展：** 同一账号 / 积分 / 素材底座上，按**场景**扩展；「电商开店」是第一个可工作场景，其它行业场景后接。近端**不承诺**跨场景业务能力。

### 1.3 刻意不对打的位置

| 类型 | 代表 | 我们近端不抢的叙事 |
|---|---|---|
| 通用 Agent 壳 | OpenClaw、Manus 类「啥都能做」 | 不宣传万能员工 / 先搭再干活 |
| 平台内助手 | 千牛 / 店小蜜、Shopify Sidekick | 不主打店内客服与后台代操作 |
| 深数据套件 | LinkFox、Helium 10 等 | 近端不做 Amazon/跨境数据全家桶 |

竞争力押在：**可交付物清楚 + 积分计费清楚 + 垂直工作流可加深**；壳可像通用 Agent，但高频任务走固定路径。

## 2. 目标用户

### 2.1 要完成的工作
- 不知道卖什么，需要一份带理由的候选清单
- 有品或选定品后，需要主图和详情页文案/展示草稿，好上架
- 希望自己操作、按次消耗，而不是雇人或定制外包
- 希望一眼感到产品会扩展更多「场景」，但当前只安心做电商开店

### 2.2 近端优先客群
- 刚做电商的一人店
- 已有店但不擅长选品的人
- 平台语境：淘宝、闲鱼、拼多多（出海后置）

### 2.3 近端非目标
- 深度定制项目需求方
- 需要人工全托代运营 / 陪跑交付的客户（近端不做主交付）
- 需要「装一个万能 Agent 替我做所有事」的用户（引导至场景内固定能力）
- 暂不按 GMV/团队规模硬性排除；若免费额度被刷，再补规则

### 2.4 关键旅程（轻量）

**UJ-0. 小陈：从首页场景画廊进入电商开店**  
小陈打开网页 → 看到若干场景大卡片（「电商开店」可点，其它灰显）→ 点亮卡进入电商场景工作台 → 见到提问门面与选品 / Listing 胶囊。

**UJ-1. 小陈：从「不知道卖啥」到拿到 10 个候选品**  
在电商场景内 → 选品类/简单条件 → 消耗积分生成清单 → 看到约 10 个候选及理由 → 决定是否再生成或进入 listing。

**UJ-2. 小陈：从候选品到一套能上架的素材**  
选定或输入一个品 → 消耗积分生成主图 + 详情文案/展示 → 下载或复制去店铺上架 → 若不满意可重试（再扣分）。

**UJ-3. 小陈：积分用完后升级**  
免费额度用尽 → 看到 Pro/Plus 与积分差异 → 订阅后积分按月重置继续用。

**UJ-4. 小陈：点到尚未开放的场景**  
在首页点灰显卡片 → 仅看到「即将推出」类提示 → **不进入**空壳工作台 → 可回到画廊或进入「电商开店」。

**UJ-5. 小陈：在场景内问到近端做不到的事**  
在电商工作台输入「帮我回千牛客服 / 做别的行业」等 → 允许短暂闲聊回应 → 明确拉回近端能力（选品 / Listing）并给出入口 → **不假装**已完成未支持任务、不扣生成积分。

## 3. 术语表

| 术语 | 含义 |
|---|---|
| 场景 | 面向一类工作的产品分区（如「电商开店」）；有独立能力边界与入口文案 |
| 场景画廊 | 首页以大卡片展示各场景；可用可点，未开放灰显可见 |
| 场景工作台 | 进入某一可用场景后的主界面：提问门面 + 该场景胶囊/固定路径 |
| 选品清单 | 一次生成得到的「可以卖什么」列表，含理由；目标约 10 条候选 |
| Listing 套装 | 一次生成得到的主图 + 详情页文案与展示说明，用于上架 |
| 积分 | 计量单位；指定生成动作消耗积分；**全站共用**（不按场景拆账，近端） |
| 套餐 | 免费版 / Pro / Plus；差异为每月积分额度 |
| 品类模板 | 按品类（如家居、电子）约束生成风格与字段的模板；三档均可使用已上线模板 |
| 积分月重置 | 订阅周期到点按档位重新发放；**未用完清零** |

## 4. 功能需求

### 4.1 账号与进入

**说明：** v1 以 **网页** 为主；小程序后续迭代。

#### FR-1：注册与登录
用户可以创建账号并登录后使用生成能力。

**可验证：**
- 未登录不能消耗积分完成生成
- 登录态下能看到当前剩余积分与套餐档

#### FR-2：套餐与积分展示
用户可以查看当前套餐（免费 / Pro / Plus）、本月剩余积分、下次重置时间。

### 4.2 积分与订阅

#### FR-3：按动作扣积分
系统在成功产出可用结果时扣积分：
- 生成一份选品清单 → 扣 **1** 积分
- 生成一套 Listing 套装 → 扣 **1** 积分

**可验证：**
- 积分不足时不能开始生成，并提示升级或等待重置
- 生成失败且未产出可用结果时不扣分或自动退回（须实现并测通）

#### FR-4：三档月积分额度
- 免费版：每月 20 积分  
- Pro：每月 200 积分  
- Plus：每月 600 积分  

#### FR-5：积分按月重置且清零
到订阅周期节点，按当前档位重新发放积分；上月剩余 **清零不结转**。

#### FR-6：订阅升级
用户可以从免费升级到 Pro 或 Plus。**月费数字待定**（按模型成本倒推）。

### 4.3 场景壳（首页与扩展位）

#### FR-13：场景画廊首页
登录前后用户打开产品首页时，先进入**场景画廊**（大卡片），而不是直接进入提问门面。  
近端即使仅「电商开店」可用，首页仍展示：**至少一张可用亮卡 + 若干未开放灰卡**。实现 UJ-0。

**可验证：**
- `/`（或约定首页）首屏为场景卡片，而非场景内提问门面
- 至少存在一个可用场景卡片「电商开店」

#### FR-14：进入场景工作台
用户点击可用场景卡片后，进入该场景的**场景工作台**（提问门面 + 该场景能力胶囊）。电商场景内承载选品与 Listing（FR-7～FR-10）。

**可验证：**
- 从画廊进入电商场景后可见提问入口与选品 / Listing 相关入口
- 工作台内可返回场景画廊

#### FR-15：未开放场景灰显
首页展示尚未支持的场景卡片为灰显但仍可见。点击灰卡仅提示即将推出（或等价文案），**不进入**可操作工作台。实现 UJ-4。

近端首页固定四张场景卡（1 亮 + 3 灰）：
- **电商开店**（可用）
- **短视频带货**（灰显）
- **小红书种草**（灰显）
- **本地生活**（灰显）

**可验证：**
- 灰卡可点出提示，无生成能力、不扣积分
- 近端画廊可见上述三张灰卡名称（文案可微调，场景身份不变）

#### FR-16：场景内短聊后拉回
在可用场景工作台中，用户输入超出该场景近端能力的请求时：允许短暂自然语言回应，然后明确说明近端支持范围，并引导至选品 / Listing（或该场景已上线能力）。实现 UJ-5。

**话术基调：友好**——先接住用户意图，再温和说明「我现在最拿手的是选品和上架素材」，并给出入口；避免生硬拒绝或冷冰列表。具体文案由 UX 定稿。

**可验证：**
- 不产生「未支持任务已完成」的假交付
- 不因纯闲聊 / 拉回引导而扣除选品或 Listing 积分
- 拉回话术可读为友好引导，而非纯错误码口吻

#### FR-17：新场景可接入的产品形状
产品须按「画廊卡片 → 场景工作台 → 场景内固定路径」的形状扩展：未来上线新场景时，增加可用亮卡并配置该场景胶囊/能力，无需改成另一种首页信息架构。

**可验证（验收口径）：**
- 文档与交互规格把「场景」列为一级导航概念
- `[NOTE FOR PM]` 具体第二个场景的业务内容不在本 PRD 近端范围

#### FR-18：账户与个人资料入口
用户可通过顶栏头像进入账户页，查看/管理显示名称与邮箱示意、使用情况（积分消耗摘要）、安全相关入口（改密、退出、删号），并可跳转套餐页。近端以实现入口与信息架构为准；改密/删号的完整校验流可后置，但页面形状锁定。

**可验证：**
- 登录态顶栏可见头像入口并进入账户页
- 账户页含个人资料、使用情况、安全三个分区（或等价导航）
- 可从账户跳转到套餐页

### 4.4 选品生成

#### FR-7：生成选品清单
用户可选择品类模板（及必要的简单输入）后生成选品清单。实现 UJ-1。

**可验证：**
- 一次成功生成给出约 **10** 个候选（允许 8–12，产品内写清）
- 每个候选含 **可卖理由**（至少一句可读说明）
- 结果可在历史中再次查看（FR-12）

#### FR-8：品类模板选用
用户可以选用不同品类模板（例如家居类、电子类）再生成。  
**规则：** 免费 / Pro / Plus **均可使用全部已上线模板**；新品类由运营排期上新，不按套餐解锁。

### 4.5 Listing 生成

#### FR-9：生成 Listing 套装
用户基于某个候选或自填商品信息，生成主图 + 详情页文案与展示说明。实现 UJ-2。

**可验证：**
- 产出物包含：主图（或主图方案）、详情文案、详情如何展示的说明
- **不是** 实体包装/纸箱设计
- v1 风格为 **国内通用** 一种，不做淘宝/闲鱼/拼多多三套强适配

#### FR-10：导出或复制
用户可以将 Listing 套装下载图片 / 复制文案，便于去店铺上架。

### 4.6 质量与反馈

#### FR-11：重试与反馈
用户可以对不满意的结果发起重试（再次扣分）或提交简短「质量差」反馈。

### 4.7 历史记录

#### FR-12：生成历史
用户可以查看本人近 **60 天**内的选品清单与 Listing 套装。

### 4.8 明确不做（近端）

- 询盘 / 客服 / 物流 / 收款自动化  
- 出海平台深度适配（Shopify / 亚马逊等）  
- 人工陪跑、代运营、效果对赌为主交付  
- 承诺销售额或 GMV  
- v1 小程序（后置）  
- v1 三平台分风格 listing  
- **宣传或交付「万能 Agent / 全领域任务」**  
- **未开放场景的假工作台或跨场景业务能力**  
- 按场景拆分积分账本（近端全站共用）

## 5. 非功能需求（NFR）

#### NFR-1：可用质量底线
选品理由可读、无明显违规胡编；Listing 文案可粘贴修改后上架。抽检比例待定。

#### NFR-2：成本可控
定价前须能统计单次选品 / 单次 Listing 的模型成本；售价须覆盖成本并留毛利。短聊拉回不得变成无界高成本工具循环（须有轮次/策略上限，实现细节见架构）。

#### NFR-3：失败可理解
失败时给人话原因（额度不足 / 服务繁忙 / 输入不完整 / 场景未开放）。

#### NFR-4：基础合规
避免明显违禁宣传；协议声明 AI 生成须人工复核后再上架。

#### NFR-5：防刷（轻量）
v1：登录 + 异常频率限制即可。

#### NFR-6：场景扩展不改首页范式
新增场景不得要求拆除「场景画廊」首页；未开放场景必须以灰显或等价方式可被产品配置，而无需发版改信息架构（配置机制可后置，但交互契约近端锁定）。

## 6. 成功指标

| 类型 | 指标 |
|---|---|
| 生意 | 付费用户数；月收入（目标感 1–2 万/月） |
| 用户价值 | 选品约 10 候选；可上架 Listing 套装 |
| 反指标 | 不以「只注册不生成」为成功；不承诺 GMV；不以「灰卡点击量」为成功 |

## 7. 风险

| 风险 | 应对方向 |
|---|---|
| 生成质量差被骂 | FR-11、NFR-1、协议要求人工复核 |
| 没人来用 | 获客与冷启动需单列运营计划（功能外，但必须有人负责） |
| 模型成本倒挂 | NFR-2；定价前实测；必要时提高单次扣分或降免费额度 |
| 灰卡过多显得「空头支票」 | 灰卡数量克制；文案「即将推出」不承诺时间；不把灰卡当成功指标 |
| 首页像通用 Agent、预期失控 | FR-16 拉回；对外话术钉在清单+Listing；场景画廊表明边界 |
| 与已实现「`/`=提问门面」不一致 | 交互改版：提问门面下沉到场景工作台（见 UX 跟进） |

- [x] 历史保留精确策略：**近 60 天**

## 9. 已确认决策摘要

- 准主业；对外上线/融资级；Coaching；愿景+功能入口  
- **定位方案 A：** 近端叙事 = 选品清单 + Listing + 积分自助；不对打通用 Agent / 平台客服  
- **多领域：** 终局按场景扩展；近端即做可扩展场景壳，**能力承诺不跨场景**  
- **交互：** 首页始终场景大卡片画廊（一张亮 + 若干灰）→ 点亮卡进场景工作台（Manus 式门面 + 胶囊）；灰卡仅即将推出  
- **超范围：** 场景内允许短闲聊再拉回；话术友好；不假装完成未支持任务  
- **近端画廊灰卡：** 短视频带货、小红书种草、本地生活  
- **账户：** 右上角头像进账户页（个人资料 / 使用情况 / 安全）；顶栏左：场景·历史·套餐，右：积分·升级·头像  
- **工作台：** 侧栏历史 + 对话 + 右侧 Computer 预览（对齐已定稿 UX）  
- 成功指标维持：付费用户数 + 月收入；用户价值约 10 候选 + 可上架素材  
- 终局全链路；近端仅选品 + listing；自助网页；积分订阅  
- 客户：一人店 / 不会选品；平台先国内三家，出海后置  
- 套餐仅积分差：20 / 200 / 600；月末清零  
- 选品与 Listing **均扣 1 积分**  
- 模板三档通用 + 运营上新；国内通用风格；小程序后置  
- 积分近端全站共用，不按场景拆账
