# Brand & Style

Adam —— 一人店「选品清单 + 上架素材」工作台。气质来自价签、店章、手机里的商品列表，而不是通用 SaaS。

# Colors

冷荧光台面纸色 + 真黑字 + **店章红**（唯一大胆色）。禁用奶油陶土、紫霓虹、薄荷绿空壳风。

# Typography

Space Grotesk 扛标题与数字；Noto Sans SC 扛中文正文。标题字距收紧，左对齐。

# Layout & Spacing

落地页：品牌 + **清单实物感**并置。工具页：工作板与列表，不用三列同款圆角卡片墙。

# Components

主按钮实心店章红、小圆角 2–4px。套餐用价目表行，不用三张孪生卡。

# Do's and Don'ts

- Do：第一眼看到交付物（清单）
- Don't：全大写 eyebrow、每段 fade-up、按钮尾部「→」
