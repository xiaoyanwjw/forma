# Adam Demo — Manus 视觉对齐版

对照 [manus.im](https://manus.im) 当前界面还原的视觉语言（非官方、非商标授权）。

## 对齐点

| Manus | 本 Demo |
|---|---|
| 白底 + 细点阵 | ✓ |
| 衬线主标题「我能为你做什么？」 | ✓（同文案结构） |
| 大圆角输入框 + / ↑ 发送 | ✓ |
| 输入框下快捷胶囊 | ✓ 选品清单 / 生成素材 |
| 登录后左侧会话栏 | ✓ |
| 右侧 Computer 工作预览 | ✓ `Adam's Computer` |

品牌名用 **adam**（小写），不使用 Manus 手形 Logo。

## 打开

```bash
open sdd/planning-artifacts/ux-designs/ux-lippi-ai-ebusiness-2026-09-24/mockups/app.html
```

点「选品清单」或「生成上架素材」→ 输入框填入带【占位符】的模板 → 改完发送。

## 交互说明

- 快捷栏在**输入框上方**；点击填入带高亮标签的模板（橙底占位符，填完变绿）
- 点标签或按 `Tab` 切换占位符；直接打字替换标签内容
- 执行步骤显示在中间对话流；右侧 Computer 只放结果预览
