# Forma Edge 推理节点正式发布

**发布日期：** 2026-03-18  
**适用读者：** 需要在局域网试开源大模型的小团队与独立开发者

## 产品概述

Forma Edge 是一款可在单机或小型服务器上运行的轻量推理节点。团队可以在不绑定公有云账号的前提下，导入 GGUF 格式权重并在浏览器控制台里发起对话与批处理任务。

官方强调：Edge 不是训练集群，也不提供多租户 SaaS；它解决的是「内网先试模型、再决定是否上云」的过渡场景。

## 硬件与安装

- 最低 **8GB RAM**；推荐 16GB 以便同时加载 7B 级量化权重。
- **CPU 必须支持 AVX2**；安装脚本会在检测失败时退出并提示更换镜像或硬件。
- 支持 **Docker Compose** 一键启动；Linux amd64 为一级支持平台。

安装完成后，控制台默认监听 `https://edge.local:8443`，首次访问需接受自签证书。

## 模型与数据

控制台提供 **GGUF 导入向导**：选择本地文件后，权重写入命名卷 `forma-edge-models`，不会自动上传到 Forma 云端。

当前版本附带三个示例配置（7B Q4、13B Q4、嵌入模型），均来自公开 Hugging Face 仓库，用户需自行确认许可证。

## 性能说明

在官方实验室环境（AMD Ryzen 9 / 32GB / NVMe）下，7B Q4 模型约 **95–110 token/s**（批大小 1）。文档明确写出：**未承诺**用户在自有硬件上达到相同数字。

## 定价与许可

Edge 节点软件在本季度对 Forma 注册用户 **免费**；仅收取可选技术支持订阅。权重与第三方依赖的许可证由用户自行遵守。
