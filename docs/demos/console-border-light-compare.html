I · 软环脉冲 · 颜色搭配

动效固定为 I（整圈边框呼吸，不转）。下面只换颜色与底色浓度。看完回字母（如 I3 / I6）。

偏「成功 / 运行中」

I1 · 现状绿

边框绿 + 淡绿底；和之前流光同一色系。

I2 · 深绿克制

更深、更淡的底；适合不想太「亮绿」时。

I9 · 薄荷绿浅

更浅更嫩；年轻一点，也可能偏「糖果」。

I8 · 绿边 + 灰底

只有边框带色，卡片底保持灰白；最不抢日志字。

I10 · 绿边白底

几乎无填充染色；动效只在边框上。

贴控制台语义色

I3 · 青绿 Teal

贴近 AGENT 标签色；像「系统在跑」。

I4 · 蓝

贴近 LLM 标签；偏「思考中」。

I5 · 琥珀

暖等待感；别和失败红混，更像「请稍候」。

更克制 / 偏产品

I6 · 石墨灰

几乎无品牌色；最安静，像终端本身。

I7 · 靛紫

偏 SaaS 产品感；和绿系差异最大。

怎么回：说颜色编号即可（如 I3、I8）。也可以说「I3 边框 + I10 白底」这种组合。
