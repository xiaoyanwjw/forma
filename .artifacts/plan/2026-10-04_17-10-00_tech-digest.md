# 科技速读 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把画廊里的 `tech_digest`（科技速读）从灰卡做成可跑通的场景：链接或粘贴 → 单页拉文（Apify WCC）→ 代码切块 → `excerpt_chunks` + `completeBatch` 旁路摘句 → 主模型只根据摘录写一页 Computer HTML → 有 view 才结算。

**Architecture:** 形状复制 `xhs-break`：Skill 在 `forma-pi-extension`，通用 tool 不进 `pi-agent`。画廊 `scene_code` 是 `tech_digest`，Skill 扫描用路径第一段当 scene，因此包必须放在 `scenes/tech_digest/tech-digest/`（**不要**放 `scenes/tech/`）。`fetch_web_page` 把正文写到 run 工作区 `source.md`，工具返回值里**不要**带全文。`excerpt_chunks` 内部切块并 `ModelProvider.completeBatch(useCase=forma.tech.excerpt)`。计费走现有 Generation 管线：`SkillRunProfile` + `ArtifactPersistPlugin`。

**Tech Stack:** Java 8 / Spring Boot 2.7 / `forma-pi-extension` tools / `pi-ai` `ModelProvider.completeBatch`（已有共享线程池）/ Apify `apify/website-content-crawler` / Vue3 Workspace spec / MySQL `forma_scene` + `forma_artifact`。

## Global Constraints

- Java 8：禁止 `var`、`record`、`List.of`、`Map.of`、private interface methods；新建集合用 `new ArrayList` / `Arrays.asList` / `Collections.emptyList`。
- 模型只经后端 `pi-ai`；前端不抓网页、不直连大模型。
- 业务 tool 只进 `forma-pi-extension`，不进 `pi-agent`。
- 密钥：`APIFY_TOKEN` 环境变量；无 Token 走 mock（与 SKU/XHS 相同）。
- 积分：仅可用 view 落库后结算；拉链失败不扣。
- 不代登、不收 Cookie、不解析 PDF、Skill 层不二次 `fetch_web_page`、不换 Actor 自动重试。
- `completeBatch` **已实现**（`pi-ai` `ModelProvider` + `ModelCompleteBatchExecutor`）。本计划禁止重写线程池。
- 产品规格：`sdd/planning-artifacts/tech-scene-plan-2026-10-04.md`。冲突时先改规格再改代码。

## Task T003: SKILL.md + launch.json

**Summary:** 写 Skill 正文与胶囊；allowed-tools 含 fetch / excerpt / write_file / read_file / render_view / read_skill。

**Milestone:** M1  
**Dependencies:** T001  
**Files:**
- Create: `forma-pi-extension/src/main/resources/scenes/tech_digest/tech-digest/SKILL.md`
- Create: `forma-pi-extension/src/main/resources/scenes/tech_digest/tech-digest/launch.json`

**Frontmatter（必须）：**

```yaml
---
name: tech-digest
description: >-
  用 fetch_web_page 或用户粘贴正文速读一篇科技产品页、AI 文章或技术文档，产出一页摘要（JSON：view + artifact）。
  在用户提到速读链接、解析文章、技术文档摘要时使用。
allowed-tools: read_skill fetch_web_page excerpt_chunks write_file read_file render_view
metadata:
  output:
    billing: true
    persistAs: tech_digest
    requiresView: true
---
```

**Workflow 要点（写进 SKILL，不要省略）：**

1. 有可用粘贴正文 → `source=paste`，**0 次** `fetch_web_page`。
2. 只有 http(s) 链接 → `fetch_web_page` **至多 1 次**；成功 `source=fetch`；用返回的 `sourcePath`（默认 `source.md`）调 `excerpt_chunks`。
3. 都没有 / fetch 失败 / 正文太短 → 只回人话，不写文件、不编造。
4. `excerpt_chunks` **恰好 1 次**。主模型总结时**只使用**工具返回的 `excerpts`，禁止把 `source.md` 全文读进总结提示（可用 `read_file` 自检 artifact，不要把 source 贴进 artifact 全文字段）。
5. 按 output.md `write_file` `artifact.json` → `render_view` → 对话仅 `{"output":"view.json"}`。
6. 超范围（订票、发帖、投顾医嘱）短聊拉回。
7. Verification 清单对齐 xhs-break：fetch 次数、source 枚举、有 excerpts、有 view、无闲聊。

**launch.json:**

```json
{
  "label": "科技速读",
  "examplePrompt": "请速读这个链接，我关心它适不适合小团队用：https://example.com/product",
  "sortOrder": 1
}
```

## Task T006: TechDigestSourcePrep 切块

**Summary:** 确定性切块：标题/空行、短段合并、<40 字并上一段、块长 800–1500、重叠约 80、最多 12、不切断 \`\`\` 代码块。
